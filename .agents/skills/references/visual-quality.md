# 视觉质量共用规则

仅当技能指向本文件时读取。各技能的流程与媒介特有规则仍以其 `SKILL.md` 为准。

## 反模板

让设计方向来自受众、品牌、内容和平台，而不是固定审美。避免无依据的 AI 紫蓝渐变、暗色网格居中 Hero、三等分卡片、满页玻璃、层层套卡、重复左右图文、无意义药丸标签、伪系统状态、空洞术语和编造的精确数据。相邻项目应更换版式、字形或色彩家族，而不是换文案复用同一模板。

卡片只用于真实层级；其余内容用留白、分隔和排版组织。每个区块承担一个主要信息任务，同页应有明显但统一的节奏变化。

## 系统一致性

先锁定并贯穿全套输出：

- 一个主色体系与最多一个强调色；
- 一套字体角色与字号层级；
- 一套圆角、描边、阴影和图标语言；
- 一套间距尺度、媒体处理和动效性格；
- 一个明暗主题；有意叙事转换除外。

同一意图的 CTA 使用同一文案。可见文案必须通顺、具体、同一语域；数据来自事实或明确标为示例。

## 排版与空间

正文保持舒适可读，标题换行由内容与容器共同决定。展示斜体含 `y/g/j/p/q` 时给足行高与下缘空间。长文本控制行宽；重要文字与背景达到 WCAG AA。标签不代替信息层级，placeholder 不代替表单 label。

大区块优先留白，但留白服务层级而非制造空洞。移动端显式定义单列、边距、阅读顺序和触控区域；全高区域用动态视口单位，避免 `h-screen` 导致移动浏览器跳动。

## 图像与图标

视觉型页面优先使用与区块匹配的真实或生成图像；产品展示用真实截图、生成图或真实可交互预览，不用矩形拼出的假界面。图标保持同一家族、同一粗细和明确语义；品牌墙使用真实标志或可信自有标志，而不是纯文字占位。

## 动效与性能

每个动画必须说明其职责：层级、叙事、反馈或状态变化。强度与设计设定一致；不为炫技叠加循环、滚动劫持或装饰运动。

优先动画 `transform` 与 `opacity`；连续指针/滚动值留在 Motion value 或浏览器动画层，不用 React state 驱动每帧重渲染。滚动显现使用 Motion、IntersectionObserver、GSAP ScrollTrigger 或 CSS scroll-driven animations，并清理监听与实例。大面积滚动内容避免 blur；`will-change` 只在活动动画期间使用。为 `prefers-reduced-motion` 提供等价静态状态。

## 交付门

交付前逐项观察最终产物，而不只检查代码：首屏与关键路径、桌面和窄屏、文字和按钮对比度、导航与触控、加载/空/错/焦点状态、图片裁切、动效降级、布局溢出、主题和视觉系统一致性。发现失败就修正后重检。
