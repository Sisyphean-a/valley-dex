# 存量界面改版

在既有产品的真实约束内，让界面更清晰、一致、有辨识度。先读[视觉质量共用规则](../references/visual-quality.md)，它是全程约束；本技能负责存量产品的审计、保留和渐进改造。

## 边界

适用于已有路由、数据、交互或设计债的 Web/App。营销页、作品集和品牌页按 `design-taste-frontend` 的完整构图流程执行；需要先由图像定义视觉事实时按 `image-to-code` 执行；只有在页面方向已定且需要奢华材质、空间或电影感动效时叠加 `high-end-visual-design`。

改版默认是保留式：不迁移框架或样式体系，不改变 URL、主导航语义、表单字段/顺序、业务文案、分析事件、SEO 和无障碍契约。确需改变任一项时，先取得用户授权并明确退役范围。

## 流程

### 1. 建立基线

先确认技术栈、样式入口、组件库、字体和图标来源、路由与关键用户路径；找出可运行的最窄检查、当前视觉 token、响应式断点和已有状态。实际观察桌面与窄屏的关键页面；有可靠方式时记录改前截图或可复现路径。

将改版归为一类：

- **保守修整**：信息架构和组件模型有效，只处理层级、token、间距和状态；
- **重点重构**：关键区块或组件阻碍理解/转化，在保留行为与内容结构下重做该处；
- **全局整理**：token 和组件规则已失控，先统一基础再逐页替换。

**完成标准：已列出保留契约、关键路径、技术边界、验证命令和本次改版类型。**

### 2. 审计问题与方向

围绕真实页面逐项找问题，不按清单机械加装饰。将发现按影响、范围和风险排序，并为每项指出对应页面/组件与改法。优先检查：

- **层级**：标题、正文、数字、标签与 CTA 是否有明确主次；行宽、换行、字重、字距和数据对齐是否服务阅读；
- **系统**：主题、主色/至多一个强调色、字体角色、间距、圆角、描边、阴影、图标和光源是否统一；
- **构图**：容器、栅格、留白、密度、对齐和移动端阅读顺序是否合理；信息卡是否真的表达层级而非层层套盒；
- **组件与内容**：是否存在通用三卡、紫蓝 AI 渐变、无意义药丸标签、假数据/假品牌、空洞文案或陈词滥调；用产品语境决定替代方式；
- **状态与质量**：关键操作是否具备 hover、active、focus、loading、empty、error、禁用和当前态；语义、对比度、触控、键盘路径、图片裁切、溢出与动效性能是否真实可用。

写一行：`改版判断：<产品/页面> 面向 <受众>，保留 <契约>，以 <视觉方向> 优先解决 <前三个问题>。` 方向必须源自品牌、内容、用户任务和现状，不能仅替换成另一套模板。

**完成标准：每个拟改动都有可观察问题、受影响范围和保留依据；视觉方向与前三项优先级明确。**

### 3. 先修系统，再修路径

按风险从低到高实施，只改能提升当前目标的部分：

1. 锁定或整理颜色、字体、间距、圆角、层级和 z-index token；沿用真实依赖，新增依赖前核对清单；
2. 调整容器、栅格、标题与内容密度，修正窄屏单列、动态视口和溢出；
3. 重做关键路径上的通用组件与视觉重点，使用留白、排版和可信媒体表达层级，而非无差别加卡片、阴影或动效；
4. 补齐所有受影响交互的状态与可访问反馈；动效只表达层级、反馈、状态或叙事，默认只动 `transform`/`opacity` 并支持 reduced motion；
5. 删除被替代的样式、组件变体和死代码，避免新旧规则并存。

保守修整做到目标已达成即停；重点重构只扩展到相邻、共享且确实阻塞一致性的部分。每完成一个关键路径，以真实操作回归其行为，不用视觉降级掩盖功能错误。

**完成标准：新视觉系统已在受影响界面落地，关键路径行为与原契约一致，替代物已清理。**

### 4. 实际验证

在目标桌面尺寸与窄屏逐页观察改动结果，至少检查：首屏或主要工作区、导航、主要 CTA/表单、长短内容、加载/空/错/焦点状态、图片和文本裁切、键盘操作、对比度、动效降级与布局溢出。运行第 1 步确认的自动化检查；改动涉及关键流程时执行对应集成或端到端检查。

发现问题先回到实现修正，再重复受影响验证；不能只因代码能构建就判定视觉改版完成。

**完成标准：受影响桌面和窄屏页面已实际观察，关键路径和自动化检查有真实结果，已知偏差均已修正或明确报告。**

## 交付门

交付前逐项核对：

- 已读取共用规则，并有改版判断、保留契约和问题优先级；
- 未迁移技术栈或改变未授权的 URL、导航、字段、内容、分析、SEO 与无障碍契约；
- token、排版、空间、表面、图标和动效形成一致系统；无无依据的模板组件、伪数据或视觉噪声；
- 所有受影响交互具备真实状态、键盘焦点与可读反馈；窄屏无溢出，动效支持 reduced motion；
- 关键路径已实际回归，替代实现已删除，最窄有效检查已运行并如实记录。

全部成立才算完成。
