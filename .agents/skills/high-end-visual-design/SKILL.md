# 高端视觉编排

目标是有触感、空间张力和流畅动效的高端网页，而不是给模板加字体。先读[视觉质量共用规则](../references/visual-quality.md)。

## 方向

根据品牌语境各选一种气质与构图，组合必须服务内容：

- **气质**：深黑微光科技；纸张颗粒与高对比排版的编辑奢华；银白、柔影和大胆 Grotesk 的软结构主义。
- **构图**：大小错落的非对称 Bento；轻微叠压和景深形成的 Z 轴层叠；巨幅文字与可横滑媒体形成的编辑分屏。

不得仅因本菜单方便而重复同一组合；当前品牌、参考或仓库已有页面撞型时，更换至少一个主轴。字形、图标和视觉语言要有品牌理由；`Inter/Roboto/Arial`、粗线通用图标、灰色 1px 边框、黑重阴影、贴顶通栏导航和整齐三等分网格都不是默认答案。**完成标准：可用一句话说明所选组合为何适合本项目。**

## 材质与空间

重要媒体或卡片可用“双层边框”：低对比外壳、细环线和少量内边距包住具有独立表面与内高光的核心，内外圆角保持同心。它是强调手段，不应包住所有内容。

主要 CTA 可使用独立尾部图标舱；按钮按下轻缩，图标产生轻微方向位移。大区块通常采用约 `6rem-10rem` 垂直空间，但以首屏可见和内容密度为上限。微型眉题只在确有层级价值时使用。

移动端在 `768px` 以下取消负边距、旋转和危险叠压，转单列、`w-full`、约 `1rem` 页面边距；全高区域用 `min-height: 100dvh`。**完成标准：材质有层级，空间有张力，窄屏仍可读可触。**

## 动效

动效表现质量与惯性，而非默认 transition：

- 浮岛导航可从紧凑胶囊扩展为全屏菜单；汉堡线条连续变形成 X，链接依序遮罩显现；
- CTA hover 产生轻微磁性位移，active 轻缩；
- 关键内容进入视口时采用缓慢 fade-up；只有性能验证允许时才用极轻 blur，并在动画结束后移除；
- 使用自定义 cubic-bezier 或弹簧；每个动画均对应层级、反馈、状态或叙事。

优先 Motion、IntersectionObserver 或 GSAP ScrollTrigger。动画默认仅改变 `transform`/`opacity`；经性能验证的小元素可短暂动画 `filter`，大面积滚动层不用 backdrop blur，噪点置于固定、无指针事件的伪元素，z-index 只服务导航、弹层、提示等系统层。**完成标准：动效实际可运行、支持 reduced motion，且不触发布局抖动。**

## 执行

1. 锁定气质、构图、字体、色彩、圆角、阴影和动效曲线。**完成标准：形成一套可复用 token。**
2. 先建立背景、巨观留白与主要排版，再加入少量高价值材质组件。**完成标准：静态页面已具备层级和识别度。**
3. 编排导航、CTA、入场与滚动动效。**完成标准：运动有因果并保持流畅。**
4. 观察桌面与移动端最终产物，修正溢出、对比度、触控和性能问题。**完成标准：实际界面而非代码想象通过检查。**

## 交付门

方向不落入通用默认；主组件的材质规则一致；移动端已解除叠压；字体、图标、边框和阴影有意选择；动效使用自定义曲线且仅动 transform/opacity；blur、噪点、will-change 和层级使用克制；最终结果在关闭动效后仍完整可用。全部成立才交付。
