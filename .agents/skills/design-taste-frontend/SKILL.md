# 有品味的前端

为落地页、作品集和视觉改版产出非模板化、可用、可交付的界面。先读[视觉质量共用规则](../references/visual-quality.md)，并把它作为全程约束。

## 边界

密集后台、数据表、多步表单、代码编辑器和原生移动端应采用对应产品模式；这里只处理它们的营销或介绍页面。

## 流程

### 1. 读场

从页面类型、受众、用户原话、参考图/网址、既有品牌资产和隐性限制中推断方向。监管、公共服务和无障碍约束优先于审美。

输出一行：`设计判断：<页面类型> 面向 <受众>，采用 <气质>，以 <设计系统或审美家族> 为基础。`

只有存在会导致两种实质不同方案的歧义时，问一个二选一问题；其余情况直接判断。随后明确三档参数：

- `DESIGN_VARIANCE`：1 对称克制，10 艺术化非对称；
- `MOTION_INTENSITY`：1 静态，10 电影化/物理感；
- `VISUAL_DENSITY`：1 展廊式，10 驾驶舱式。

默认 `8/6/4`。极简/公共服务下调变化与动效；品牌/实验项目上调；改版从现状起步。**完成标准：方向、三档值及理由明确。**

### 2. 选基础

当产品语境明确归属正式系统时，核对 `package.json` 后使用官方包：Microsoft 用 Fluent，Google 用 Material 3，IBM 用 Carbon，Shopify 用 Polaris，Atlassian 用 Atlaskit，GitHub 用 Primer，英国/美国公共服务用 GOV.UK/USWDS。可访问 React 基础可用 Radix；自有 SaaS 可用经深度定制的 shadcn/Tailwind。

一个项目只用一个系统。玻璃、Bento、粗野主义、编辑风、暗黑科技、动效排版和所谓 Web Liquid Glass 都是审美，不冒充官方系统；用原生 CSS/维护良好的组件实现并如实标注。导入第三方包前确认已安装，否则先给安装命令。

默认工程纪律：Next.js 静态布局保持 Server Component；交互与 Motion 隔离到最小 `'use client'` 叶节点；新项目用 `motion/react`；连续值用 Motion value；字体经 `next/font` 或自托管；图标统一选 Phosphor、HugeIcons、Radix 或 Tabler 中的一家。**完成标准：基础与现有工程兼容，依赖真实存在。**

### 3. 构图

根据档位选择版式，不套默认模板。首屏必须在小型笔记本初始视口内看清：桌面标题最多 2 行，说明默认不超过 20 词/4 行，CTA 无需滚动即可见，顶部留白不超过约 `6rem`。首屏文字角色最多四组：眉题或品牌条、标题、说明、CTA；信任墙移到下一节。导航桌面单行且不高于 80px。

同一页面至少形成多种区块节奏：同一布局家族默认只出现一次；信息结构确需复用时也不得连续出现；左右图文交错最多连续两节；8 节页面至少四种布局家族。Bento 的单元数与内容数严格相等，并以图像、纹理或底色形成真实差异。眉题最多每三节一个。默认不用“左大标题 + 右小解释”的分栏标题。

内容默认每节一个短标题、一段短说明和一个视觉或 CTA。超过五项时改用分组、网格、标签页、折叠、横滑或轮播，而不是拉长列表。引用正文最多三行；同一 CTA 意图只保留一种文案。**完成标准：首屏、节奏、内容密度与移动端折叠均可画出明确结构。**

### 4. 视觉与交互

锁定一套主题、强调色和圆角规则。Serif 只在明确的编辑、出版、历史或奢侈语境使用；现代创意项目默认选择有性格的 sans display。`Fraunces`、`Instrument Serif`、Inter 和紫蓝辉光都不是无条件默认值。高端消费项目也不自动套米白 + 黄铜/赭色 + 咖啡黑。

视觉页面至少使用有意义的真实或生成图像；有图像生成工具时优先生成区块专用素材。Hero 需要真正的视觉，不用渐变 blob 或 div 假截图顶替。品牌墙只展示标志，不附行业小标签。

为交互提供 loading、empty、error、focus 和 active 状态。按钮文字桌面不换行，并检查按钮、表单、placeholder、错误信息的对比度。动效强度大于 4 时，必须实际实现有理由的入场、关键滚动或反馈动画；做不到就把档位降到 3。页面最多一个 marquee，不用裸 `scroll` 监听。

**完成标准：视觉系统贯穿全页，状态完整，动效与档位一致。**

### 5. 改版分支

先判断：保留式改版、彻底改版或绿地。保留式改版先审计品牌 token、信息架构、内容块、关键路径、标志性交互、可访问性、分析事件和 SEO 基线，再依次尝试字体、间距、色彩、动效、关键区块重构；够用即停。

未经明确批准，保持 URL/slug、主导航文案、表单字段名与顺序、品牌标志、法律/同意文案不变。彻底改版可重做视觉，但仍保留内容与信息架构，除非用户另有授权。**完成标准：保留项和退役项均有依据，隐性契约未变。**

## 交付门

交付前机械检查并修正：

- 设计判断、三档和基础选择已经声明；改版已先审计；
- 首屏、导航、CTA、主题、强调色、圆角、字体和移动端折叠符合上述规则；
- 眉题数 `≤ ceil(区块数/3)`，无三连图文交错、空 Bento 单元或重复 CTA 意图；
- 所有可见文案已通读，无破句、空洞营销话、装饰性版本号/滚动提示/伪地点时间条、无来源的精确数字；页面可见文案不用破折号 `—`；
- 图片真实可用，无 div 假截图、纯文字假品牌墙或图片上的无意义标签；
- 动效有职责、支持 reduced motion、实例可清理；窄屏无溢出；
- 依赖、加载/空/错/焦点状态、对比度和 Core Web Vitals 已用实际产物验证。

每项都能诚实通过才算完成。
