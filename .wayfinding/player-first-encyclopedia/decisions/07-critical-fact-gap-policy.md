# 关键事实缺口策略

## 问题

当官方资产不能直接或稳定回答玩家核心问题时，产品应在省略、明确未知、可验证推导或独立维护的有来源补充数据之间采用什么准入规则？

## 答案

### 官方证据优先阶梯

玩家核心事实存在缺口时，builder 按单条事实依次检查：

1. 目标实体的官方字段、旧格式字段和本地化字符串；
2. 已支持的商店、地点、机器、鱼塘等官方表及稳定跨表关系；
3. 与该事实相关、尚未识别的官方 JSON；
4. 官方日程、事件、邮件、地图和条件命令；
5. 必要时复现特定游戏版本的官方程序集规则，并明确标为“依据官方代码计算”；
6. 仍无法稳定回答时，才进入补充事实准入或明确未知。

“穷尽官方资产”按单条事实的相关证据范围判断，必须记录检查路径和停止理由，不要求先解析整个游戏。明显可由官方实体稳定连接的事实必须优先完成跨表推导，不能绕过调查直接手工填写。

### 补充事实准入

允许 builder 独立维护少量**有来源补充事实**，但必须同时满足：

- 回答已确认分类契约中的玩家核心问题；
- 已按官方证据优先阶梯完成相关路径调查；
- 官方资产无法稳定表达所需玩家语义；
- 事实稳定、可逐条复核并具有明确适用游戏版本；
- 不用于补齐低价值技术字段、主观攻略或优化建议。

补充事实由 builder 在统一数据契约中合并和裁决；app 仍只消费数据包与 `WikiCatalogue`，不得运行时联网或直接读取第二套 Wiki 文件。

### 来源与内容边界

每条补充事实至少记录：

- 实体、事实键、结构化值和适用条件；
- 独立的 `supplemental` 来源类别；
- 来源页面 URL、页面修订号和修订时间；
- 适用游戏版本、平台和语言；
- 人工审核时间、审核状态和过期状态；
- 与官方候选及其他补充来源的冲突状态。

补充层只人工提炼短小结构化事实，不复制 Wiki 描述、攻略段落或表格文本。页面修订只证明来源版本，不证明内容必然正确。补充事实不得写入官方派生区域、使用官方来源标记或提升为官方结论。

### 冲突与版本漂移

- 官方直接证据优先于补充事实；可复现的官方跨表关联和官方代码计算也优先于补充事实。
- 补充事实与官方证据冲突时立即失效，不自动覆盖官方事实。
- 多个补充来源冲突时发布未知，不通过投票选择答案。
- 游戏版本变化后，受影响的补充事实先标记待复核；完成复核前不能作为固定答案。
- 只有明确与版本无关的稳定语义映射可以跨版本保留，但仍须按发布周期复核。

### 缺口与发布

- 核心事实缺失时显示未知或暂未收录，不能静默省略，也不能用相似技术字段替代。
- 单条已明确标记的缺口不自动阻断整个数据包。
- 来源不明、冲突未解决、条件丢失或已过期未复核的值拒绝发布。
- 非官方事实冒充官方来源，或同游戏版本的核心覆盖无解释地大幅退化时，阻断整个数据包。
- 分类覆盖比例、必须达标类别及包级阈值留给决策 12；具体 schema 和版本迁移留给决策 09。

### 语义所有权

- builder 的 `context:offline-official-data` 拥有官方路径调查、补充事实准入、来源隔离、冲突裁决和版本复核。
- app 的 `context:offline-encyclopedia` 只按统一发布契约展示结果与来源类别，不自行抓取、合并或推断补充事实。

## 依据

- 用户在 2026-08-13 对官方证据阶梯、补充事实准入、来源与内容边界、冲突/版本策略和缺口发布规则确认“全部接受”。
- 当前 builder 仅将 `FishPondData.json`、`Locations.json`、`Machines.json` 和 `Shops.json` 作为官方支持表，发现报告中仍存在未识别官方资产；因此未调查相关路径时只能称暂未收录，不能宣称官方无答案。
- 大型可制作物配方产物可由 `crafting_recipe.outputItemId/outputEntityType` 建立官方反链；商店地点、工具升级流程、怪物层段、武器宝箱奖励和鱼水域等还可能涉及事件、地图、条件或程序集规则。
- 当前 `data/overrides.zh-CN.json` 只应承担展示覆盖，不能成为无来源事实补丁；app 直接读取第二套补充文件会绕过 `WikiCatalogue` 内容边界。
- 中英文 Stardew Valley Wiki 的 MediaWiki `siteinfo` API 在 2026-08-13 返回 `Creative Commons Attribution-NonCommercial-ShareAlike`；中文站修订 API 可返回页面 `revid` 与时间戳。为避免复制文本带来的许可义务和内容污染，本决定只允许人工提炼短小结构化事实并保存修订来源。
